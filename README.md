# Аврора · Таро

Сайт таролога в виде старинной книги: главы о тарологе, карта дня, пробный расклад, атлас 78 карт,
кабинет клиента, запись на консультацию, отзывы с видео и коллекция карт.

## Запуск на этом компьютере

1. Дважды щёлкните `start.bat`. Откроется браузер с адресом http://127.0.0.1:8000/.
2. Окно с чёрным текстом — это сервер. Пока оно открыто, сайт работает. Закрыли окно — сайт выключился.

## Мастерская (админ-панель)

Один раз создайте свой вход в мастерскую. В папке сайта откройте PowerShell и выполните:

    uv run python manage.py createsuperuser

Программа спросит почту и пароль. Потом заходите на http://127.0.0.1:8000/masterskaya/.

В мастерской:
- **Профиль сайта** — имя, город, текст «О тарологе», контакты, почта для уведомлений.
- **Услуги и цены**, **Вопросы и ответы**, **Как проходит консультация** — тексты на главной.
- **Окна для записи** — свободное время. Действие «Повторить выбранные окна через неделю» копирует расписание.
- **Записи на консультацию** — подтвердить, отметить «состоялась», написать заметку клиенту.
- **Отзывы клиентов** — посмотреть видео и опубликовать. Без согласия клиента отзыв не публикуется.
- **Опыт: истории и видео** — ваши истории из практики с видео.

## Письма

Для настоящих писем один раз запустите двойным щелчком `setup-email.bat`. Мастер использует
установленный Git Bash и предложит три шага:

1. Выбрать ящик **отправителя**: Яндекс, Mail.ru или Rambler. Получать письма могут пользователи
   любой почты — отдельный отправитель для каждого сервиса не нужен.
2. Открыть официальную инструкцию, ввести полный адрес и пароль для почтовой программы. Для Яндекса
   и Mail.ru создаётся отдельный пароль приложения; для Rambler следуйте его инструкции и разрешите
   доступ почтовых программ. Пароль вводится скрыто, в чат его присылать не нужно.
3. Сохранить настройки и, по вашему согласию, отправить тестовое письмо. Проверьте «Входящие» и «Спам».

Настройки сохраняются только в локальном `.env`, который исключён из Git. Не пересылайте этот файл.
Переменные, заданные на хостинге, имеют приоритет над `.env`; пароль читается буквально, без подстановки
переменных из его текста. Пример имён настроек — `.env.example`.

После настройки закройте прежнее окно сервера и снова запустите `start.bat`. Если аккаунт уже создан,
**не регистрируйтесь повторно**: войдите с прежними почтой и паролем, чтобы получить подтверждение.
Откройте ссылку в письме и нажмите «Подтвердить и войти». Пока адрес сайта — `127.0.0.1`,
ссылку нужно открывать на том же компьютере, где запущен сайт.

Без SMTP-настроек остаётся режим разработки: письма сохраняются в `var\sent-emails`, в интернет
они не отправляются. Страница подтверждения сообщает, что настоящая почта пока не подключена.
Ошибка почтового сервера не удаляет аккаунт: после исправления настроек отправку можно повторить через вход.

Официальные инструкции: [Яндекс](https://yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/mail-clients-troubleshooting),
[Mail.ru](https://help.mail.ru/mail/login/mailer/), [Rambler](https://help.rambler.ru/mail/mobile/2037/).

## Где лежат данные

Всё — в папке `var`: база `db.sqlite3`, видео в `media`, письма в `sent-emails`. Эта папка не попадает в git.
Делайте её копию, чтобы не потерять клиентов и видео.

## Для разработчика

- Тесты: `uv run python manage.py test tests`
- Снимки страниц: `node tools/shoot.mjs home,/collection/ 390,1440` (переменные `AURORA_URL`, `AURORA_SESSION`).
- Перед размещением в интернете: переменные окружения из начала `aurora/settings.py`, хостинг в России (данные клиентов из РФ по 152-ФЗ).
